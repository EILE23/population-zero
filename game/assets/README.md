# Assets — how the game's things are made

Everything the player sees is **vector**: SVG files under `svg/<category>/<name>.svg`, generated by `../tools/assets.mjs`
and checked by `../tools/lint-assets.mjs`. Text in, pictures out — so the autonomous developer can add and fix assets,
the style cannot drift, and the cost is zero. Image models are for posters *inside* the world, never for game art.

## The look
Paper and ink. A `#3a2f36` ink line (2.4px at scale 1, 1.6px for fine parts), flat fills from `palette.json`, no gradients,
no shadows, no filters, no text. The brand mauve (`#ad7096`, `#7b526c`) is an accent: a door, a roof edge, a sign — never a wall.
Shapes are simple and a little crooked on purpose; nothing is pixel-perfect symmetrical.

## The grid
- 1 SVG unit = 1 screen px at depth `d = 1` (the front). The engine scales by `0.7 + 0.3·d`, the same as the web.
- **Origin is the foot point**: `viewBox="-w/2 -h w h"`, so `(0, 0)` is where the thing touches the ground, centred.
  A figure is 42px tall to the top of its head; a bench seat is at y = -15; a lamp is about 90; a house facade 150–220.
- Keep a prop under 240px wide and 260px tall; buildings under 420×260; sky things whatever.

## Categories (folders)
`props` (street furniture, park things), `buildings` (facades you can walk into), `flora` (trees, bushes, beds),
`vehicles`, `animals`, `sky` (clouds, sun), `items` (things a figure can carry: hat, cup, broom — 16–28px),
`ui` (icons for the legend and menus).

## Adding one
1. Add an entry to `../tools/assets.mjs` (a few lines with `rect`/`circle`/`path`/`poly`/`line`), run `node game/tools/assets.mjs`.
2. `node game/tools/lint-assets.mjs` must pass (viewBox, palette, forbidden elements, size).
3. Open `scenes/gallery.tscn` in Godot to see it next to the others. `Prop` draws any asset by `"category/name"`.
4. Every asset that is a *place* needs a use (a pose at it) and a resident that goes there — the same rule as the web.

## Why not sprites / an image model
Sprite sheets rot: the moment someone wants the bench in another colour or 20% wider, the pipeline is a person with a
paint program. SVG from code re-renders at any depth scale, diffs in git, and the CI developer can maintain it.
