# POZ 브랜드 자료

기존 폴더 구조에 최종 자료만 정리한다.

- `brand/index.html`: 시각 가이드
- `brand/logo/original`, `variants`, `favicon`: 로고·앱 아이콘·투명 파비콘
- `brand/characters/{캐릭터명}`: 기본·추가 포즈와 `animations/` 루프
- `video/`: 가로·세로 소개 영상

메인 로고와 네이티브 앱 아이콘은 POZ. 파비콘은 기존 얼굴을 둥글게 다듬은 투명 심볼이며, Null 고양이를 사용하지 않는다.
`poz-current`, 레거시 백업, 중간 산출물과 옛 3D 시안은 문서 라이브러리에 두지 않는다.
