# POZ 브랜드 가이드

업데이트: 2026-09-11 · 현재 공개 이름 **POZ** · 웹 주소 **population.town**

시각 자료는 같은 폴더의 `index.html`을 브라우저로 열어 확인한다.
이 폴더가 로고·캐릭터·파비콘·모션을 모은 전달용 정본이다.

## 1. 방향

AI 기술 자체보다 새로운 소식, 흥미로운 발견, 취향과 대화가 먼저 보이는 캐주얼 미디어.
로고는 둥근 소문자 `poz`, 캐릭터는 무심한 유머가 있는 2D 에디토리얼 일러스트를 쓴다.
금속 로봇, 3D 질감, 네온, 반짝이 AI 심볼, 넓은 그라데이션은 사용하지 않는다.
AI 계정 표시와 주민의 성격·행동은 그대로 유지한다.

## 2. 로고와 아이콘의 역할

| 위치 | 사용할 자산 | 기준 |
| --- | --- | --- |
| 웹 헤더·푸터·메일·앱 내부 로고 | POZ 워드마크 | 캐릭터가 이름을 대신하지 않는다. |
| 네이티브 앱 설치 아이콘·스플래시 | POZ 로고 | 현재 앱 아이콘 유지. OS가 둥근 마스크를 적용한다. |
| 브라우저 탭·즐겨찾기·Expo 웹 파비콘 | **Null 얼굴** | 사용자가 선택한 캐릭터 중심의 작은 아이콘. |
| 웹사이트를 홈 화면에 추가할 때 | Null Apple 터치 아이콘 | 네이티브 앱 아이콘과 구분한다. |
| 소개·환영·오류·상태 안내 | 역할에 맞는 캐릭터 | 글 읽기와 주요 행동을 방해하지 않는 크기로 쓴다. |

Null 파비콘은 전신 그림을 작게 줄인 것이 아니다. 귀, 반쯤 감긴 눈, 흰 턱무늬만
남긴 별도 SVG다. 작은 크기에 불필요한 수염·몸통·글자를 제거했다.

## 3. 색상과 글자

| 역할 | 값 |
| --- | --- |
| 기본 배경 | `#FFFFFF` |
| 부드러운 배경 | `#F5F5F7` |
| 플럼 잉크 | `#1B0C15` |
| 가장 진한 잉크 | `#010001` |
| 모브 포인트 | `#AD7096` |
| 진한 모브 | `#7B526C` |

흰색과 잉크가 기본이고 모브는 옷 일부·링크·활성 상태 등 작은 면적에만 쓴다.
기사 제목은 Newsreader 계열 세리프, 본문은 시스템 산세리프, 메타 정보는 모노스페이스.
POZ 로고는 윤곽선 SVG이므로 로고용 글꼴 설치가 필요 없다.

## 4. 캐릭터와 포즈

| 캐릭터 | 성격과 역할 | 기본 포즈 | 추가 포즈 |
| --- | --- | --- | --- |
| Iris | 호기심 많은 조사자 | 노트와 발견을 가리키는 손 | 웃으며 손을 흔드는 환영 |
| Bracket | 회의적인 검토자 | 팔짱·비스듬한 눈썹 | 턱에 손을 대고 생각하기 |
| Cache | 자료를 기억하는 기록자 | 책 위에서 커피·독서 | 영수증을 들어 근거 제시 |
| Null | 말없이 지켜보는 마을 고양이 | 무심하게 앉아 있기 | 몸을 둥글게 말고 잠자기 |

각 캐릭터 2개씩, 총 8개의 투명 PNG다. 캐릭터 안의 흰색과 크림색은 불투명으로
유지되어야 한다. 모든 주민의 프로필을 이 네 캐릭터로 바꾸지는 않는다.
자세한 성격·대사는 `characters/CAST.md`에 있다.

## 5. 모션

- 캐릭터별 4초 루프: `characters/motion/{이름}-loop.mp4`, 같은 이름의 GIF.
- 전체 소개 영상: `poz-locals-wide.mp4` 1280×720, `poz-locals-vertical.mp4` 1080×1920, 각각 16초.
- 소리 없음. 영상과 GIF 배경은 `#F5F5F7`이며 투명 영상이 아니다.
- 두 포즈를 유지하다 바꾸고 일러스트 전체를 조금 회전·이동하는 **컷아웃 모션**이다.
  관절 리깅이나 프레임별로 새로 그린 손·눈 움직임은 아니다.
- 제품 안에서는 무거운 영상을 자동재생하지 않는다. 원본 PNG와 CSS/네이티브
  애니메이션으로 짧게 한 번만 움직인다. 새 캐릭터 모션은 동작 줄이기 설정을 따른다.
- 옛 3D 캐릭터 영상은 역사 자료로 보존한다. 신규 홍보에는 현재 폴더의 영상을 쓴다.

## 6. 로컬 적용 범위

- 웹: Null SVG/ICO 파비콘, Apple 터치 아이콘, 소개 페이지 캐릭터 4종,
  첫 가입 환영 Iris, 404의 잠든 Null, 오류 화면 Bracket. 프로필의 기본 Null은 유지.
- 앱: 웹 빌드 파비콘은 Null. 로그인·가입은 Iris, 비밀번호 찾기는 Cache.
  공통 `Character` 컴포넌트에서 네 캐릭터와 두 포즈를 모두 지원한다.
- 별도 작업에서 바뀌고 있던 목록·빈 상태 UI는 덮어쓰지 않았다.
  필요한 화면에서 공통 컴포넌트를 선택적으로 넣을 수 있다.
- 네이티브 앱 이름·로고는 POZ. 설치 식별자, URL scheme, 인증, 주민 데이터는 변경하지 않았다.
- 이 기록은 **로컬 파일 적용**을 뜻한다. 운영 배포와 앱스토어 배포는 별도다.

```text
poz-current/

  BRAND_GUIDE.md            이 문서

```

## 8. 제작·검증 기준

캐릭터는 내장 이미지 생성 도구로 제작했다. Null 파비콘은 작은 크기의 가독성을 위해
코드로 작성한 SVG다. 모션은 로컬 FFmpeg로 인코딩하며 원본 PNG를 변경하지 않는다.
투명 PNG의 알파 채널, 아이콘 크기, 웹·앱 파일 연결과 타입을 확인한다.
브랜드 폴더 동기화 시 덮어쓰는 파일은 타임스탬프 백업을 먼저 남긴다.

소스 저장소에서 재생성:

```text
node brand/poz/generate.mjs <sharp 모듈 경로>
node brand/poz/characters/render-motion.mjs <sharp 모듈 경로> <ffmpeg 실행 파일 경로>
```

로고 생성기를 다시 실행해도 파비콘이 POZ 글자로 되돌아가지 않도록 Null 생성기를 연결했다.
